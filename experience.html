工地大脑 - 信息聚合与超级制单联动系统

面向建造业的信息聚合与结构化处理平台，通过业微工作会话SDK自动采集项目群消息，解析为结构化事件并联动超级制单系统实现业务闭环。

  • 信息聚合：通过业微工作会话数据SDK实现项目群消息自动采集，构建"信息聚合层 → 结构化处理层 → 三局通接入层"三层架构
  • 结构化处理：将群消息自动解析为结构化事件（包含基本信息、事件类型、关联人员等字段），生成任务清单
  • 角色链路：设计项目总监→实施经理→安全员→监理员等角色的工作场景链路，覆盖信息聚合→事件识别→任务派单→安全审核全链路
  • 超级制单联动：支持制单任务自动下发、任务状态实时同步、到期自动提醒，与业微超级制单系统打通形成完整业务闭环

Agent · PPT 生成 核心项目
AIPPT - 多 Agent 协作 PPT 生成系统

基于 HiAgent 平台搭建的智能 PPT 生成系统，通过多 Agent 串联编排实现从文档上传到 PPT 生成的全流程自动化。

  • 多 Agent 编排：Start → 文件提取 → 10 要素校验 → 知识库检索 → 页面规划 → 详细撰写 → 质量审查 → End 八节点流程
  • 10 要素校验：产品定位、受众群体、页数要求、设计风格、主色调、排版密度、功能组件、受众痛点、业务场景、展示案例
  • 智能追问：要素缺失时自动启动追问流程，支持简单模式（5-7 分）与高级模式（8-10 分）自动切换
  • 质量保障：质量审查节点确保关键约束无遗漏，页数结构与设计风格符合要求
